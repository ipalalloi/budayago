# Staging SOP (manual, gated)
1. Preserve SCK-007 source, archive DB backups and verify hashes. Do NOT run against `sck_uat` or `sck_ci`; never reset existing database.
2. Create a dedicated blank staging MySQL/MariaDB database, dedicated least-privilege account; first apply `database/mysql.sql` to blank database, then `database/20261119_heritage_additive.sql`. For an existing approved SCK-007 staging clone, apply ONLY the additive migration after backup. All schema changes require review.
3. Setup PHP >=8.2 with `pdo_mysql`, `fileinfo`, `mbstring`, session support, `upload_max_filesize >= 12M`, `post_max_size > 12M`. Config from private `config.example.php` copy to root `config.php` (untracked), define `DB_DSN`, credentials, `APP_ORIGIN`, `FORCE_HTTPS=true`, private LOGIN_RATE_LIMIT_DIR.
4. Set vhost document root to `.../BUDAYAGO_LIVING_HERITAGE_PWA_v0.2_ALPHA/public`, HTTPS enabled, no direct access to app/ database/ docs/ private_media/ config.php. Create `private_media` outside web-served docroot, permissions 0700, PHP-FPM owner; disable directory indexing and file execution.
5. Setup admin via original SCK-007 provisioning instructions after checking actual presence of CLI `bin/install-admin.php` (NOT included in review ZIP; obtain separately from verified canonical source if missing). Review account roles and `holder` cultural authority before testing.
6. Verify home `heritage.php` + `index.php`, login, create synthetic holder + curator, draft, test JPEG/PNG/photo, submit, holder consent, admin publish, guest view, withdrawal, direct URL denial, contribution moderation. Verify file limits, browser offline draft metadata, PWA install and no caching private requests. Do not use real cultural people or recordings before approvals.
7. Run inherited security regression, database integration with disposable fixture, documented HTTP security UAT, and independent security review. Gate manual approval before public exposure.

**Rollback:** Stop public access to successor `heritage.php` and restore previous vhost release / SCK-007 artifact. Retain additive tables and private media in secure escrow for review; do NOT drop tables, delete media, roll back live DB, or overwrite consent records automatically. Complete approved data retention/disposal separately. Restore only from a verified backup if authorized.
